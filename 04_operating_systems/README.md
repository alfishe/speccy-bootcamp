# Operating Systems

ZX Spectrum ROM variants, DOS systems, and ROM-defined workspace. The Spectrum has no traditional OS — the ROM BASIC interpreter IS the operating system. Disk-based DOSes (TR-DOS, +3 DOS, ESXDOS) layer on top.
