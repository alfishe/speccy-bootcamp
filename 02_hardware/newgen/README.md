# Hardware — New Generation

This directory covers modern ZX Spectrum hardware: ZX Spectrum Next, Sprinter, ZX Evolution, ZX-Uno, Karabas family, and Peridot.

> This directory covers the **programming-relevant** modern hardware platforms. Originally planned articles for `zx_evo.md`, `baseconf.md`, `zx_uno.md`, `karabas_pro.md`, `karabas_128.md`, and `peridot.md` were **descoped** — the ZX Evolution and ZX-Uno are already comprehensively covered in [11_emulation/fpga/](../../11_emulation/fpga/) (`zxevo.md`, `zx_uno_core.md`), and the Karabas/Peridot family are pure-hardware clones that run standard Spectrum software with no new programming APIs. The remaining planned articles (ZX Spectrum Next family, Sprinter, TS-Conf) all expose unique programming interfaces. See [PLAN.md](../../PLAN.md) for details.
